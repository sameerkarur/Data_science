# Interview Q&A — Python Variables & Data Types

| # | Question | Answer |
|---|----------|--------|
| 1 | Mutable vs immutable types in Python? | **Mutable:** list, dict, set. **Immutable:** int, float, str, tuple, frozenset. |
| 2 | Difference between `==` and `is`? | `==` compares **values**; `is` compares **identity** (same object in memory). |
| 3 | What is dynamic typing? | Variable type is determined at **runtime**, not declared upfront. |
| 4 | How do you check type of a variable? | `type(x)` or `isinstance(x, int)`. |
| 5 | What is `None` in Python? | A singleton object representing **absence of value**. |
