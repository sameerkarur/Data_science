# Interview Q&A — Imbalanced Data

| # | Question | Answer |
|---|----------|--------|
| 1 | What is SMOTE? | **Synthetic Minority Over-sampling** — creates synthetic minority samples. |
| 2 | Precision vs Recall? | **Precision** = TP/(TP+FP). **Recall** = TP/(TP+FN). |
| 3 | When prefer Recall? | When **missing positives is costly** (e.g. employee churn, fraud). |
| 4 | ROC-AUC meaning? | Area under ROC curve; measures ranking ability across thresholds. |
| 5 | Stratified split why? | Preserves **class ratio** in train/test sets. |
