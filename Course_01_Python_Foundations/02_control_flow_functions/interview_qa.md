# Interview Q&A — Python Control Flow & Functions

| # | Question | Answer |
|---|----------|--------|
| 1 | `*args` vs `**kwargs`? | **`*args`** = variable positional args (tuple). **`**kwargs`** = variable keyword args (dict). |
| 2 | List comprehension vs loop? | Comprehension is **more concise** and often **faster** for simple transforms. |
| 3 | `return` without value? | Returns **`None`**. |
| 4 | Scope: local vs global? | **Local** inside function; **global** module-level. Use `global` keyword to modify global. |
| 5 | Lambda use case? | Short **anonymous functions**, often in `map()`, `filter()`, `sort(key=...)`. |
