## 🏗️ Architectural Differences (V1 vs V2)

| Dimension | Version 1 Baseline | Version 2 Advanced Implementation |
|---|---|---|
| **Analytical Scope** | Aggregated descriptive totals (Sales by state/group) | Multi-Dimensional Behavioral Segmentation & Econometrics |
| **Customer Profiling** | None (purely macro transactions) | RFM (Recency, Frequency, Monetary) Quantile Persona Clustering |
| **Retention Dynamics** | Static date slices | Period-over-Period Cohort Matrix analyzing repeat repurchase rates |
| **Pricing Intelligence**| Simple revenue per unit division | Empirical Price Elasticity of Demand via Log-Log Ordinary Least Squares |
| **Strategic Utility** | Post-mortem reporting | Dynamic marketing targeting, churn mitigation & yield optimization |
