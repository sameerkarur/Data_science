# Interview Q&A — Clustering

| # | Question | Answer |
|---|----------|--------|
| 1 | K-Means steps? | Pick k → assign to nearest centroid → recompute centroids → repeat until convergence. |
| 2 | How to choose k? | **Elbow method**, **silhouette score**, domain knowledge. |
| 3 | K-Means vs hierarchical? | K-Means: fast, needs k. Hierarchical: dendrogram, no fixed k upfront. |
| 4 | What is silhouette score? | Measures how similar a point is to its cluster vs other clusters (-1 to 1). |
| 5 | When is clustering used? | Customer segmentation, anomaly detection, recommendation cohorts. |
