# Interview Q&A — Prompt Engineering

| # | Question | Answer |
|---|----------|--------|
| 1 | Good prompt structure? | **Role + Context + Task + Format + Constraints + Examples**. |
| 2 | Zero-shot vs few-shot? | **Zero-shot** = no examples; **Few-shot** = include example inputs/outputs. |
| 3 | What is chain-of-thought? | Ask model to **reason step-by-step** before final answer. |
| 4 | How reduce hallucinations? | Ground in data, ask for citations, lower temperature, verify outputs. |
| 5 | Temperature parameter? | Higher = more **creative/random**; lower = more **deterministic**. |
