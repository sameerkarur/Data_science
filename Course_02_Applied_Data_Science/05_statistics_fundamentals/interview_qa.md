# Interview Q&A — Statistics

| # | Question | Answer |
|---|----------|--------|
| 1 | Parameter vs statistic? | **Parameter** = population value (μ, σ); **Statistic** = sample estimate (x̄, s). |
| 2 | Descriptive vs inferential? | **Descriptive** summarizes data; **Inferential** draws conclusions about population. |
| 3 | What is skewness? | Measure of **asymmetry** of a distribution. |
| 4 | Type I vs Type II error? | **Type I** = reject true H₀ (false positive). **Type II** = fail to reject false H₀. |
| 5 | When use t-test vs z-test? | **t-test** when σ unknown / small n; **z-test** when σ known / large n. |
