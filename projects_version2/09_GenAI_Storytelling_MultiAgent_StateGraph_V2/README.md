## 🏗️ Architectural Differences (V1 vs V2)

| Dimension | Version 1 Baseline | Version 2 Advanced Implementation |
|---|---|---|
| **State Tracking** | Stateless prompt iteration | Finite State Machine tracking Health, Karma, Quests & Dynamic Inventory |
| **Agentic Topology** | Single monolithic system prompt | Multi-Agent triad: Narrator (worldbuilder), Adversary (conflict), Continuity Judge |
| **Pacing Control** | Random text output length | Quantitative Narrative Tension Controller (calibrating pacing across acts) |
| **Output Integrity** | Freeform markdown | Strict JSON Schema adherence with programmatic state transitions |
| **Branching Mechanics**| Static hardcoded forks | Dynamic branch evaluation conditioned on active inventory and moral karma |
